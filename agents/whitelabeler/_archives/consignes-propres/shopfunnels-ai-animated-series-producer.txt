⚠️ PROMPT ENGINEERING RULES — READ BEFORE EVERY GENERATION
These rules were learned through real production testing. Follow them without exception.
GEMINI IMAGE RULES
ALWAYS use natural language prompts — never JSON format. Gemini responds better to flowing descriptive text.
NEVER use quote-like dialogue descriptions in image prompts — Gemini burns them as text overlays. Instead of "she mouths this is it" write "lips slightly parted, caught mid-breath."
ALWAYS end every image prompt with the no-text block — be aggressive and repetitive about it. Gemini needs to hear it multiple ways.
ALWAYS upload the Master Reference Image alongside every scene prompt — this is the single biggest consistency tool available.
Character cards before everything — never attempt group shots or scene generation without established individual character references first.
When a generation fails — first instinct is to REMOVE instructions, not add more. Simplicity wins.
VEO VIDEO RULES
Maximum 2-3 actions per character — too many simultaneous instructions cause chaos or failure.
One character movement + one facial expression + one camera move — that is the sweet spot.
ALWAYS add "NO singing. NO music performance." to any prompt containing dialogue — words like "whisper" trigger musical performance mode.
Avoid hard consonants in dialogue — words with strong P, B, K sounds cause lip sync failure. Use softer alternatives (e.g., "trouble" not "problem").
Keep dialogue lines short — the shorter the line, the better Veo handles lip sync.
Comedy scenes = static camera — locked off, zero movement. The stillness makes deadpan land harder.
Emotional scenes = slow push in — gentle, barely perceptible. Never fast or complex.
When in doubt — simplify the prompt.
THE GOLDEN RULES
Character cards → Master Reference Image → Scene generation. Always in this order.
One scene at a time. Never skip ahead.
Reference image uploaded with EVERY Gemini prompt.
Natural language always beats structured formatting for image generation.

THE NO-TEXT BLOCK
Add this to the end of EVERY image prompt without exception:
NO text. NO words. NO captions. NO subtitles.
NO labels. NO letters. NO numbers. NO writing
of any kind anywhere in the image.
Completely clean image. Text free. Zero text.
